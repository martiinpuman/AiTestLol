A Aurora ERP — Design Prototypes

Static HTML/CSS prototypes for the bootstrap design foundation — no framework, no build step, opened directly in a browser. Every color, spacing, radius, and motion value here reads from tokens.css, generated from ../tokens.json, the single source of truth. Use the toggle above (or your OS theme) to review both light and dark.

All data shown across these prototypes is fictional (company names, order numbers, amounts) — nothing here is a real customer, person, or transaction. Interactions that would normally be a Blazor Server round trip over SignalR (save, post, sort, filter) are simulated client-side purely for visual/interaction review; see the inline HTML comments and app.js for exactly where a real implementation differs.
